# Isha's Personal Portfolio

🌐 **Live Portfolio:** [isha-isha-portfolio.netlify.app](https://isha-isha-portfolio.netlify.app/)

A personal portfolio website showcasing my academic background, technical skills, internship experience, and projects in Computer Science, Artificial Intelligence, and Machine Learning.

## ✨ Features

- Personal introduction and profile
- Academic background and education timeline
- Internship experience at Xebia IT Architects and Arsalley
- Technical skills and technology stack
- Featured projects with descriptions and technologies
- Downloadable resume
- Viewable internship certificates
- Responsive and interactive UI

## 💻 Projects

### 1. Deepfake Detection System
A multimodal deep-learning system that detects deepfake content using facial images and voice signals.

**Tech Stack:** Python, PyTorch, OpenCV, Librosa

### 2. Dynamic Context Compression Engine
An LLM-based solution using RAG, embeddings, and vector retrieval to manage long conversational contexts through adaptive compression and context reconstruction.

**Tech Stack:** Python, LangChain, LangGraph, Embeddings, Vector Retrieval, LLMs, RAG

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/IshaVishwas/my-portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd my-portfolio
   ```

3. Open `index.html` in your browser or use the Live Server extension in VS Code.
